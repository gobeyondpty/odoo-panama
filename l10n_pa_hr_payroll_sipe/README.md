# Panama - SIPE Planilla Export

Generates the bulk-upload XLSX file accepted by the Caja de Seguro Social
(CSS) SIPE web portal at <https://sipe.css.gob.pa/>.

## Installation

Add this repo to the Odoo addons path and install the module:

```bash
odoo-bin -d <db> -i l10n_pa_hr_payroll_sipe --stop-after-init
```

Depends on `l10n_pa_hr_payroll` (Panama payroll core) which itself depends on
Enterprise `hr_payroll`.

## Usage

1. Configure each Panama employee:
   - **Settings → Employees → <employee> → HR Settings → Panama / SIPE**
   - Fill **SIPE Tipo de Documento** (Cédula / Pasaporte / Seguro Social)
   - Fill **Número de Seguro Social (CSS)**
2. Configure salary rules:
   - **Payroll → Configuration → Salary Rules → <rule> → General → Panama / SIPE**
   - Set **SIPE Column** to the SIPE column the rule contributes to
   - This module ships sensible defaults for the rules in `l10n_pa_hr_payroll`
3. Confirm payslips for the period as usual.
4. Generate the SIPE file:
   - **Payroll → Reporting → Exportar planilla SIPE**
   - Pick the empleador (company) and period
   - Click **Generar archivo SIPE** and download the resulting `.xlsx`
5. Upload to SIPE:
   - Log in to <https://sipe.css.gob.pa/>
   - Ingresos → Planillas → Planilla Regular → select empleador / grupo /
     periodo → **Cargar Archivo** → **Seleccionar archivo**
   - Pick the downloaded `.xlsx` and confirm

## File format

25 columns (A through Y), header row in row 1, data from row 2,
`.xlsx` extension. Column order:

| # | Column | Source |
|---|---|---|
| A | Tipo de Documento | `hr.employee.l10n_pa_sipe_id_type` |
| B | Número de Documento | `hr.employee.identification_id` |
| C | Número de Seguro Social | `hr.employee.l10n_pa_css_number` |
| D | Nombre | derived from `hr.employee.name` |
| E | Apellido | derived from `hr.employee.name` |
| F | Sueldo | sum of payslip lines tagged `sueldo` |
| G | Horas Extras | sum of payslip lines tagged `horas_extras` |
| H | Impuesto Sobre Renta | sum of payslip lines tagged `impuesto_sobre_renta` |
| I | Décimo Tercer Mes | sum of payslip lines tagged `decimo_tercer_mes` |
| J | Vacaciones | sum of payslip lines tagged `vacaciones` |
| K | Comisiones | sum of payslip lines tagged `comisiones` |
| L | Bonificaciones | sum of payslip lines tagged `bonificaciones` |
| M | Combustible | sum of payslip lines tagged `combustible` |
| N | Dieta | sum of payslip lines tagged `dieta` |
| O | Salario en Especie | sum of payslip lines tagged `salario_en_especie` |
| P | Viáticos | sum of payslip lines tagged `viaticos` |
| Q | Gasto de Representación | sum of payslip lines tagged `gasto_representacion` |
| R | Impuesto Sobre Renta Gasto Representación | sum of payslip lines tagged `impuesto_sobre_renta_gasto_representacion` |
| S | Décimo Tercer Mes Gasto Representación | sum of payslip lines tagged `decimo_tercer_mes_gasto_representacion` |
| T | Primas de Producción | sum of payslip lines tagged `primas_de_produccion` |
| U | Dividendo | sum of payslip lines tagged `dividendo` |
| V | Participación Beneficio Ingresos | sum of payslip lines tagged `participacion_beneficio_ingresos` |
| W | Gratificación Aguinaldo | sum of payslip lines tagged `gratificacion_aguinaldo` |
| X | Preaviso | sum of payslip lines tagged `preaviso` |
| Y | Indemnización | sum of payslip lines tagged `indemnizacion` |

Reference: CSS *Manual de Carga Masiva de Planilla V2* (2018), section 2.1
"Formato de carga".

## Workflow note

The CSS SIPE bulk-upload feature has two modes:

- **Standalone upload** — the file generated by this module is uploaded
  directly. Works when CSS recognizes employees by Número de Seguro Social
  (CSS already has the cédula on file).
- **Template-based upload** — the operator first downloads the SIPE-
  generated template (which includes period and employee group already
  populated) and copies values into it. Use this if the standalone mode
  rejects employees as "Cédula no verificada".

## Compliance Notice

This module produces a file matching the documented SIPE format. It does
NOT verify that the encoded amounts are correct under Panama labor law,
nor that the CSS will accept them. Run the file through SIPE's
*Consulta de Errores* page after upload and resolve any flagged rows.

## Private Data Policy

Never commit:

- real CSS Seguro Social numbers
- real cédulas
- real employee names or salaries
- generated SIPE files

The repo `.gitignore` covers `private/` paths and `*.xlsx` artifacts.
